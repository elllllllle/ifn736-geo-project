Key takeaways

The same 3 conversations win, every method

Q01 (Bali couple), Q02 (family, domestic) and Q08 (family, Fiji) are the only scenarios that ever surface Flight Centre — in recall, in live search, and once content is injected. Every other persona (solo, backpacker, senior, corporate, last-minute, adventure) never produces an organic mention, method notwithstanding.

Discoverability is the bigger lever

The 5.1% → 39.9% jump only happens once Flight Centre's content is already in the conversation. Search grounding alone barely moves reach (5.1% → 23.8%, same 3 conversations) — the problem is being considered as a candidate at all, not page structure.

V4 clears significance — on one run

Full + Tables (V4) jumps to 43.3% excl. Book — nearly double baseline's 21.7% — and is the first variant in this project to clear conventional statistical significance (Fisher's exact p = 0.019). That's a real early signal, but it's still Run 1 of up to 4 planned; the next step is replicating it across the remaining team runs before treating it as a recommendation.
